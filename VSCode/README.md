# VSCode Setup

This page provides instructions for setting up VSCode fit for Java programming.

- [ ] Download and install the [Java](https://www.java.com/en/download/) runtime.
- [ ] Download and install [VSCode](https://code.visualstudio.com/download).

You can also find here a list of the most common environment issues along with the actions that can be taken to address them:

1. VSCode does not recognize the `main()` entry point in order to launch a program.  
2. Java Source code is plagued by multiple misleading red squiggly lines.

Lastly, when everything else fails, here are the step-by-step guides to:

{:start="3"}
1. Check whether the Java IDE is installed correctly and completely.
2. Reset completely the configuration of VSCode in order to eliminate the most persistent issues.
