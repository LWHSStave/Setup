# VSCode Setup

This page provides instructions for setting up VSCode fit for Java programming.

1. Download and install [Java](https://www.java.com/en/download/) runtime.
2. Download and install [VSCode](https://code.visualstudio.com/download). 

You can also find here a list of most common environment issues and actions that can be taken to address them:

3. VSCode does not recognize the `main()` entry point in order to launch a program.  
4. Java Source code is plagued by multiple misleading red squiggly lines.

Lastly, when everything else fails, here are the step-by-step guides for:

5. Verify weather the Java IDE is correctly and completely installed.  
6. Fully reset VSCode configuration to eliminate some more stubborn environment issues.
